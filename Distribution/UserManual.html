Overview

Ultimate DebugView++ is a powerful enhancement of the classic Windows debug output viewer. It captures and displays debug output from Windows applications using OutputDebugString API, kernel-mode drivers, and various other sources.

Key Capabilities

Multiple Sources

Capture debug output from Win32 applications, kernel drivers, log files, TCP/UDP sockets, and named pipes.

Advanced Filtering

Create complex include/exclude filters with regex support, process filtering, and message highlighting.

Tabbed Interface

Organize debug streams into multiple tabs with independent filters and views.

High Performance

Handle millions of messages efficiently with optimized circular buffers and minimal overhead.

📥 Import Settings from DebugView++

Ultimate DebugView++ provides seamless migration from the original DebugView++, preserving all your customizations and configurations.

Automatic Import on First Run

When you run Ultimate DebugView++ for the first time, it automatically detects if you have DebugView++ installed and offers to import your settings.

💡 Tip: The import process is non-destructive. Your original DebugView++ settings remain unchanged, allowing both applications to coexist.

What Gets Imported

  • Views and Tabs: All your saved views with their names and configurations
  • Filters: Include/exclude filters, highlight filters, and process filters
  • Column Layouts: Column visibility, order, and width settings
  • Window Position: Size and position of the main window
  • Font Settings: Both main list and detail pane fonts
  • Preferences: Auto-scroll, process colors, clock time, and other settings
  • Custom Colors: Your color palette for filters and highlights

Manual Import

You can manually import settings at any time:

  1. Go to Options → Import DebugView++ Settings...
  2. Confirm the import when prompted
  3. Restart Ultimate DebugView++ to apply the imported settings

Registry Locations

Application Registry Path
Original DebugView++ HKEY_CURRENT_USER\Software\CobaltFusion\DebugView++
Ultimate DebugView++ HKEY_CURRENT_USER\Software\ClarionLive\UltimateDebugView++
⚠️ Note: If you choose to import settings when Ultimate DebugView++ already has settings, your current Ultimate DebugView++ settings will be overwritten.

🔧 Clarion Debug Format Support

Native support for Clarion application debugging with automatic parsing of structured debug messages.

Message Format

Clarion messages following this format are automatically parsed:

[||]X,T:<threadId>,P:<procedureName>,M:<moduleName>,A:<appName>,PRE:<prefix>,MSG:<message>

Example

[||]X,T:1234,P:InitDatabase,M:MainModule.clw,A:MyApp.exe,PRE:DB,MSG:Connecting to database...

Benefits

  • Automatic column population for better organization
  • Filter by thread, module, or procedure
  • Clean message display without format metadata
  • Track execution flow across procedures
  • Professional structured debug output

🚀 Auto-Create Process Views

Applications can automatically create and manage their own debug views by sending a special marker message.

How It Works

  1. Application sends OutputDebugString("@@NEWDEBUGVIEW@@")
  2. DebugView++ automatically creates or switches to a view for that process
  3. View is cleared if it already exists (fresh debugging session)
  4. All subsequent messages from that process appear in its dedicated view

Implementation Example

// C++ Example #ifdef _DEBUG OutputDebugString(L"@@NEWDEBUGVIEW@@"); OutputDebugString(L"Application started"); // All following debug output goes to dedicated view #endif // C# Example #if DEBUG System.Diagnostics.Debug.WriteLine("@@NEWDEBUGVIEW@@"); System.Diagnostics.Debug.WriteLine("Application started"); #endif
💡 Tip: Perfect for multi-application debugging scenarios where each app needs its own isolated debug stream.

  1. Extract UltimateDebugviewpp.exe and fsqlf.dll to a folder
  2. Run UltimateDebugviewpp.exe
  3. If you have DebugView++ installed, you'll be prompted to import your settings
  4. No additional dependencies or installation required!

First Run Checklist

1. Enable Dark Mode

Go to View → Dark Mode if you prefer a dark interface

2. Show Detail Pane

Press Ctrl+D to enable the detail pane

3. Configure Columns

Right-click column headers to show/hide columns for your needs

4. Set Up Filters

Use Log → Filter... to create include/exclude rules

5. Enable Process Colors

Turn on View → Process Colors for visual separation

6. Save Configuration

Use File → Save Configuration to save your setup

🔧 Troubleshooting

Common Issues

Q: SQL formatting not working?

A: Ensure fsqlf.dll is in the same folder as the executable. The DLL is loaded dynamically and will fall back to basic formatting if not found.

Q: Dark mode not affecting title bar?

A: Title bar theming requires Windows 10 version 1809 or later. Earlier versions will only theme the application content.

Q: Can't see Clarion columns?

A: Right-click on any column header and enable the Clarion-specific columns (Thread, App, Module, Procedure, Prefix).

Q: Detail pane not showing?

A: Press Ctrl+D or use View → Show Detail Pane. The detail pane is hidden by default on first run.

Q: Lost column configuration?

A: Right-click column header → "Reset Layout" to restore default configuration, or load a previously saved layout.

Performance Tips

  • Disable syntax highlighting for very large messages
  • Use filters to reduce the number of displayed messages
  • Clear old messages periodically with Ctrl+X
  • Limit the log history size in Options
  • Close unused tabs to free memory
