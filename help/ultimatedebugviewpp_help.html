Introduction

UltimateDebugView++ is an enhanced version of DebugView++ specifically designed for Clarion programmers and advanced debugging scenarios. It features:

  • Modern Ribbon UI for easy access to all features
  • SQL query formatting and beautification
  • Syntax highlighting with Scintilla editor
  • Advanced filtering and message categorization
  • Support for Clarion debug messages with structured data
  • Queue and Group visualization
  • Multi-tab interface for organizing debug sessions
  • High-performance message handling (50,000+ messages/second)

Getting Started

System Requirements

  • Windows 7 or later (64-bit recommended)
  • Visual C++ 2022 Runtime
  • .NET Framework 4.7.2 or later (for some features)
  • Administrator privileges (optional, for kernel message capture)

Installation

  1. Download UltimateDebugViewpp.exe
  2. Extract to your preferred directory
  3. Run UltimateDebugViewpp.exe
  4. Optional: Run as Administrator to capture kernel messages

First Run

On first run, UltimateDebugView++ will:

  1. Create a default configuration in %APPDATA%\UltimateDebugView++
  2. Start capturing Win32 OutputDebugString messages automatically
  3. Display the main window with the Ribbon interface

Capturing Debug Messages

Message Sources

UltimateDebugView++ can capture messages from multiple sources:

1. Win32 OutputDebugString

Automatically captures all OutputDebugString API calls. This is the primary source for Clarion debug messages.

2. Log Files

Monitor and "tail" log files in real-time. What is tailing? Tailing means continuously watching a file for new content that gets added to the end. As your application writes new lines to the log file, UltimateDebugView++ automatically displays them immediately - just like watching a live stream of your log file. This is especially useful for monitoring active applications that are continuously writing to their log files.

To monitor a log file:

  1. Click File → Open... (Ctrl+O)
  2. Browse to the log file you want to monitor
  3. Select the file
  4. UltimateDebugView++ will display the existing contents and automatically show any new lines as they're written to the file

Alternative method using Sources dialog:

  1. Click Log → Sources...
  2. Click "Add" button
  3. Enter a descriptive name (e.g., "MyApp Error Log")
  4. Choose "File" from the Type dropdown
  5. Enter or browse to the file path
  6. Click OK and enable the source with the checkbox

Note: The file monitoring continues even if the file is deleted and recreated (common with rotating log files). UltimateDebugView++ will automatically detect and follow the new file.

3. Network Sources (TCP/UDP)

Receive debug messages over TCP or UDP:

  1. Click Log → Sources...
  2. Click "Add" button
  3. Enter a descriptive name
  4. Choose TCP Socket or UDP Socket from the Type dropdown
  5. Enter IP address (for listening, use 0.0.0.0 for all interfaces)
  6. Enter port number
  7. Click OK
  8. Enable the source by checking the checkbox

4. DebugView Agent

Connect to remote DebugView Agent for debugging remote machines:

  1. Click Log → Connect DebugView Agent
  2. Or use Log → Sources... and add a DebugView Agent source

5. Named Pipes

Named pipes are handled automatically when data is piped to DebugView++ from the command line.

Message Format

Messages are displayed with:

  • Index - Sequential message number
  • Time - Timestamp (optional)
  • Process - Source process name and ID
  • Message - The debug message content

Filtering and Highlighting

Filter Types

Include Filters

Show only messages matching the filter:

  1. Press F5 or click Filter button
  2. Add Include filter
  3. Enter text or regex pattern
  4. Apply filter

Exclude Filters

Hide messages matching the filter:

  • Right-click on a message → Exclude
  • Or use Filter dialog → Add Exclude filter

Highlight Filters

Color-code messages for easy identification:

  1. Select text in a message
  2. Press Ctrl+H or right-click → Highlight
  3. Choose highlight color

Token Filters

Extract and display only specific parts of messages using regex groups.

Filter Syntax

  • Simple Text: Matches anywhere in message
  • Wildcards: Use * and ? for pattern matching
  • Regular Expressions: Full regex support with capture groups
  • Process Filters: Filter by process name or ID

Quick Filters

Apply temporary filters without opening the dialog:

  • Ctrl+I - Include selected text
  • Ctrl+E - Exclude selected text
  • Ctrl+H - Highlight selected text
  • Ctrl+K - Create token from selection

Saving and Loading Filters

  1. Configure your filters
  2. Click Save in Filter dialog
  3. Name your filter set
  4. Load saved filters from the dropdown

SQL Formatting

UltimateDebugView++ includes powerful SQL formatting capabilities:

Automatic SQL Detection

Automatically detects and formats SQL queries in debug messages when they contain SQL keywords.

Manual Formatting

  1. Select a message containing SQL
  2. Click Format → Format SQL
  3. View the beautified query in the detail pane

Formatting Options

  • Indentation: Configure spaces or tabs
  • Keyword Case: UPPERCASE, lowercase, or Capitalize
  • Line Breaks: Before/after keywords
  • Alignment: Align operators and commas

Supported SQL Dialects

  • Standard SQL
  • Microsoft SQL Server
  • MySQL
  • PostgreSQL
  • SQLite

Syntax Highlighting

The Scintilla editor provides syntax highlighting for various formats:

Supported Languages

  • SQL - Automatic for SQL queries
  • XML/HTML - For structured data
  • JSON - For JSON debug output
  • C/C++ - For code snippets
  • Clarion - For Clarion code

Customization

  1. Right-click in detail view
  2. Select "Syntax Highlighting"
  3. Choose language or "Auto-detect"

Color Schemes

  • Default - Light background
  • Dark - Dark theme
  • Custom - Define your own colors

Managing Views and Tabs

Creating New Views

  1. Press Ctrl+N or File → New View
  2. Each view has independent filters
  3. Name tabs for easy identification

Tab Operations

  • Rename: Right-click tab → Rename
  • Duplicate: Right-click → Duplicate View
  • Close: Click X or middle-click tab
  • Reorder: Drag tabs to reorder

Linked Views

Link views to synchronize scrolling:

  1. Select multiple tabs (Ctrl+Click)
  2. Right-click → Link Views
  3. Linked views scroll together

View Persistence

Views are automatically saved and restored between sessions, including:

  • Tab names and order
  • Active filters
  • Column widths
  • Scroll positions

Clarion-Specific Features

UltimateDebugView++ includes special support for Clarion debugging:

Structured Message Recognition

Automatically parses Clarion debug messages with the format:

[||]X,T:<thread>,P:<procedure>,M:<module>,A:<app>,PRE:<prefix>,MSG:<message>

Queue Display

When receiving queue data from Clarion:

  • Automatically formats as a table
  • Column headers from field names
  • Sortable columns
  • Export to CSV

Procedure Tracking

Track procedure entry/exit with [Open] and [Close] messages:

  • Collapsible procedure blocks
  • Execution time calculation
  • Call stack visualization

SQL Trace Integration

For Clarion SQL operations:

  • Automatic SQL extraction
  • Parameter substitution display
  • Execution time tracking
  • Error highlighting

Field Name Mapping

Maps Clarion field prefixes to readable names when [||FieldNames||] messages are received.

Advanced Features

Regular Expression Support

Use regular expressions for powerful filtering:

  • Pattern matching with capture groups
  • Case-sensitive/insensitive options
  • Multiline matching
  • Named groups for token extraction

Example Patterns:

Error:\s*(\d+)          # Match error codes
\[SQL\].*SELECT.*       # Match SQL SELECT statements
^Process:\s*(.+)$       # Extract process names
(?i)warning|error       # Case-insensitive warnings or errors

View detailed statistics about captured messages:

Export Options

Performance Optimization

For high-volume debugging:

  • Buffer Size: Adjust in Options → Performance
  • Update Frequency: Reduce for better performance
  • Filters: Use exclude filters to reduce noise
  • Virtual Mode: Enable for millions of messages

Remote Debugging

Debug applications on remote machines:

Troubleshooting

Common Issues

No messages appearing

  • Check if capture is paused (Space key)
  • Verify no exclude filters are blocking messages
  • Ensure source application is running
  • Run as Administrator for kernel messages

Performance problems

  • Reduce buffer size in Options
  • Clear old messages regularly
  • Use exclude filters for noise
  • Disable syntax highlighting for high volume

SQL formatting not working

  • Check SQL dialect setting
  • Ensure fsqlf_dll.dll is present
  • Verify SQL syntax is valid

Clarion messages not structured

  • Verify UltimateDebug class is configured correctly
  • Check UsePlainFormat property is FALSE
  • Ensure messages use [||]X format

Log Files

Debug logs are stored in:

%APPDATA%\UltimateDebugView++\Logs\

Reset Configuration

To reset all settings:

  1. Close UltimateDebugView++
  2. Delete %APPDATA%\UltimateDebugView++
  3. Restart application
