Getting Started

The UltimateDebug class provides comprehensive debugging capabilities for Clarion applications. It sends formatted messages to UltimateDebugView++, which can filter, highlight, and analyze your debug output.

Basic Setup

INCLUDE('UltimateDebug.INC'),ONCE

MyDebug  UltimateDebug

CODE
  MyDebug.Debug('Application started')
  ! Your code here...

Core Debug Methods

Debug

Debug(STRING pDebugString, <STRING pCustomPrefix>, BYTE pNoClip = 0, BYTE pForce = 0, <STRING pID>)

Sends a debug message to UltimateDebugView++.

Parameters:

  • pDebugString - The message to send
  • pCustomPrefix (optional) - Custom prefix for filtering (e.g., '[SQL]', '[ERROR]')
  • pNoClip - Set to 1 to preserve trailing spaces
  • pForce - Set to 1 to force output even if DebugOff is TRUE
  • pID (optional) - Unique ID to group related messages

Example:

MyDebug.Debug('Processing customer: ' & CLIP(CUS:Name))
MyDebug.Debug('SQL Query executed', '[SQL]')
MyDebug.Debug('Critical error!', '[ERROR]', , 1)  ! Force output

DebugQueue

DebugQueue(*QUEUE pQueue, <STRING pMsg>, <BYTE pNoTouch>, BYTE pSendToDebugView=0, LONG pMaximumRecords=30)

Displays the contents of a queue in a formatted table or sends it to the debug viewer.

Parameters:

  • pQueue - Reference to the queue to debug
  • pMsg (optional) - Description message
  • pNoTouch (optional) - Set to 1 to not change queue pointer
  • pSendToDebugView - Set to 1 to send to debug viewer instead of showing window
  • pMaximumRecords - Maximum records to display (default: 30)

Example:

CustomerQ  QUEUE
Name         STRING(50)
Balance      DECIMAL(10,2)
           END

! Fill queue...
MyDebug.DebugQueue(CustomerQ, 'Customer List', , 1)  ! Send to viewer

DebugGroup

DebugGroup(*GROUP pGroup, <STRING pMsg>, <STRING pStructureType>, BYTE pSendToDebugView=0)

Displays the contents of a group structure.

Parameters:

  • pGroup - Reference to the group to debug
  • pMsg (optional) - Description message
  • pStructureType (optional) - Type description (e.g., 'Record')
  • pSendToDebugView - Set to 1 to send to debug viewer

Example:

Customer  GROUP
ID          LONG
Name        STRING(50)
          END

MyDebug.DebugGroup(Customer, 'Current Customer', 'Record', 1)

DebugRecord

DebugRecord(*FILE pFile, <STRING pMsg>)

Displays the current record buffer of a file.

Parameters:

  • pFile - Reference to the file
  • pMsg (optional) - Description message

Example:

GET(Customers, CUS:ID_Key)
IF ~ERRORCODE()
  MyDebug.DebugRecord(Customers, 'Found customer')
END

DebugEvent

DebugEvent(<STRING pDebugProcedure>)

Logs Windows event information including event type, field, focus, and other event details.

Parameters:

  • pDebugProcedure (optional) - Procedure name for context

Example:

! In your ACCEPT loop
ACCEPT
  MyDebug.DebugEvent('MainWindow')
  CASE EVENT()
  ! ... handle events
  END
END

Initialization Methods

Init

Init(<STRING pProcedure>, <STRING pModuleName>, <STRING pAppName>, <STRING pModified>) ,LONG

Initializes debugging for a procedure. Tracks procedure entry and manages thread context.

Parameters:

  • pProcedure - Procedure name
  • pModuleName - Module name
  • pAppName - Application name
  • pModified - Last modified date/time

Returns:

Procedure ID for use with EndOfProcedure

Example:

ProcessCustomers  PROCEDURE
ProcID  LONG

CODE
  ProcID = MyDebug.Init('ProcessCustomers', 'CUSTPROC.CLW', 'MyApp.EXE')
  ! Procedure code...
  MyDebug.EndOfProcedure(ProcID)

EndOfProcedure

EndOfProcedure(LONG pID)

Marks the end of a procedure for tracking purposes.

Parameters:

  • pID - Procedure ID returned from Init()

Configuration Methods

SetPrefix

SetPrefix(STRING pPrefix)

Sets the default prefix for all debug messages.

Example:

MyDebug.SetPrefix('[MODULE1]')
MyDebug.Debug('This message will have [MODULE1] prefix')

BeginTemporaryPrefix / EndTemporaryPrefix

BeginTemporaryPrefix(STRING pPrefix)
EndTemporaryPrefix()

Temporarily changes the message prefix. Useful for grouping related messages.

Example:

MyDebug.BeginTemporaryPrefix('[TRANSACTION]')
MyDebug.Debug('Starting transaction')
MyDebug.Debug('Processing items')
MyDebug.Debug('Committing')
MyDebug.EndTemporaryPrefix()

AddCategoryToDebug

AddCategoryToDebug(STRING pCategory)

Adds a debug category for filtering purposes.

AddProcedureException / RemoveProcedureException

AddProcedureException(STRING pProcedureName)
RemoveProcedureException(STRING pProcedureName)

Excludes or includes specific procedures from debug output.

Example:

! Exclude noisy procedure
MyDebug.AddProcedureException('RefreshDisplay')

! Later, re-enable it
MyDebug.RemoveProcedureException('RefreshDisplay')

Utility Methods

ClearDebugView

ClearDebugView()

Clears the UltimateDebugView++ output window. Sends the special "DBGVIEWCLEAR" message.

Example:

MyDebug.ClearDebugView()  ! Start with clean output

UseFilteredView

UseFilteredView()

Switches to a filtered view in UltimateDebugView++.

TurnOnTracing / TurnOffTracing

TurnOnTracing(FILE pFile)
TurnOffTracing(FILE pFile)

Enables or disables SQL tracing for a file.

Example:

MyDebug.TurnOnTracing(Customers)
! SQL operations will be logged
OPEN(Customers)
! ...
MyDebug.TurnOffTracing(Customers)

Error / ErrorCode

Error(<STRING pMessage>) ,BYTE
ErrorCode(<STRING pMessage>) ,BYTE

Logs error information including ERRORCODE(), ERROR(), ERRORFILE(), etc.

Returns:

Current ERRORCODE() value

Example:

GET(Customers, CUS:ID_Key)
IF MyDebug.Error('Failed to get customer')
  ! Handle error
END

DecToHex

DecToHex(LONG pNumber) ,STRING

Converts a decimal number to hexadecimal string.

Example:

MyDebug.Debug('Color value: ' & MyDebug.DecToHex(COLOR:Red))

Properties

Property Type Default Description
DebugOff BYTE FALSE Set to TRUE to disable all debug output
DebugPrefix STRING(60) '' Default prefix for all messages
SaveToFile BYTE FALSE Set to TRUE to save debug output to file
ASCIIFileName STRING 'DebugLog_*.txt' Filename for debug log
SaveToJson BYTE FALSE Set to TRUE to save in JSON format
JSONFileName STRING '' Filename for JSON output
UsePlainFormat BYTE FALSE Use plain text format instead of structured
DebugNoCR BYTE FALSE Suppress carriage returns in output
ShowAll BOOL TRUE Show all event details
ShowField BOOL FALSE Show field information in events
ShowThread BOOL FALSE Show thread ID in events

Code Examples

Complete Application Example

PROGRAM

INCLUDE('UltimateDebug.INC'),ONCE

MyDebug      UltimateDebug
Customers    FILE,DRIVER('MSSQL')
Record         RECORD
ID               LONG
Name             STRING(50)
Balance          DECIMAL(10,2)
               END
             END

CustomerQ    QUEUE
Name           STRING(50)
Balance        DECIMAL(10,2)
             END

CODE
  ! Initialize debugging
  MyDebug.SetPrefix('[MAIN]')
  MyDebug.Debug('Application starting')

  ! Turn on SQL tracing
  MyDebug.TurnOnTracing(Customers)

  OPEN(Customers)
  IF MyDebug.Error('Failed to open Customers file')
    HALT(1, 'Cannot open database')
  END

  MyDebug.BeginTemporaryPrefix('[LOADING]')
  SET(Customers)
  LOOP
    NEXT(Customers)
    IF ERRORCODE() THEN BREAK.

    CustomerQ.Name = CUS:Name
    CustomerQ.Balance = CUS:Balance
    ADD(CustomerQ)

    IF CUS:Balance < 0
      MyDebug.Debug('Negative balance: ' & CLIP(CUS:Name) & ' = ' & CUS:Balance, '[WARNING]')
    END
  END
  MyDebug.EndTemporaryPrefix()

  ! Display the queue
  MyDebug.DebugQueue(CustomerQ, 'Loaded Customers', , 1)

  CLOSE(Customers)
  MyDebug.Debug('Application ending')

Error Handling Pattern

TryOperation  PROCEDURE
RetVal  BYTE(0)

CODE
  MyDebug.BeginTemporaryPrefix('[OPERATION]')

  ! Attempt operation
  DO SomethingRisky

  IF ERRORCODE()
    MyDebug.Error('Operation failed')
    MyDebug.DebugRecord(MyFile, 'Failed record state')
    RetVal = 1
  ELSE
    MyDebug.Debug('Operation successful')
  END

  MyDebug.EndTemporaryPrefix()
  RETURN RetVal

Queue Processing with Debug

ProcessQueue  PROCEDURE(*QUEUE Q)
Counter  LONG

CODE
  MyDebug.Debug('Processing queue with ' & RECORDS(Q) & ' records')

  LOOP Counter = 1 TO RECORDS(Q)
    GET(Q, Counter)

    MyDebug.Debug('Processing record ' & Counter, '[DETAIL]')

    ! Process record...

    IF Counter % 100 = 0
      MyDebug.Debug('Processed ' & Counter & ' records', '[PROGRESS]')
    END
  END

  MyDebug.Debug('Queue processing complete')

Message Format

Messages sent to UltimateDebugView++ use a special format that enables advanced filtering and processing:

Standard Format

[||]X,T:<thread>,P:<procedure>,M:<module>,A:<app>,PRE:<prefix>,MSG:<message>

Components:

  • [||]X - Message marker for UltimateDebugView++
  • T: - Thread ID
  • P: - Procedure name
  • M: - Module name
  • A: - Application name
  • PRE: - Message prefix/category
  • MSG: - Actual message content
  • I: - Optional unique ID for grouping

Special Prefixes

UltimateDebugView++ recognizes these special prefixes:

  • [Open] - Procedure entry
  • [Close] - Procedure exit
  • [Queue] - Queue data
  • [Group] - Group/structure data
  • [Events] - Windows events
  • [Assert] - Assertion messages
  • [ERROR] - Error messages
  • [SQL] - SQL operations
  • [||FieldNames||] - Field name definitions

Clear Command

Send "DBGVIEWCLEAR" to clear the debug window:

MyDebug.Debug('DBGVIEWCLEAR')  ! Or use MyDebug.ClearDebugView()

New View Command

Send "@@NEWDEBUGVIEW@@" to create a new filtered view:

MyDebug.UseFilteredView()  ! Creates new view tab
