Main Window

Understanding the main window layout and components of UltimateDebugView++.

Window Layout

The main window consists of several key areas:

1. Toolbar and Menu Bar

The toolbar at the top provides quick access to common functions:

  • Standard mode: Compact icons for space efficiency
  • Expanded mode: Icons with text labels (Options → Expanded Toolbar)
  • Menu bar: Full access to all features organized by category
  • Customizable: Settings persist between sessions

2. Message List View

The central area displays captured debug messages with columns for:

  • Line: Sequential message number
  • Time: Message timestamp (customizable format)
  • Process: Source process name and ID
  • Message: The actual debug output text

3. Tab Bar

Below the toolbar, tabs allow you to:

  • Create multiple filtered views of the same data
  • Switch between different capture sessions
  • Organize messages by source or filter criteria
  • Right-click tabs for context menu options

4. Detail Pane

The optional detail pane (toggle with F4) shows:

  • Full message text with syntax highlighting
  • Formatted SQL queries when detected
  • JSON/XML structure visualization
  • Copy and export options

5. Status Bar

The bottom status bar displays:

  • Total message count
  • Filtered/visible message count
  • Capture status (running/paused)
  • Active filters indicator
  • Memory usage

Window Management

Resizing and Docking

  • Drag pane borders to resize
  • Double-click borders to auto-size
  • Toggle detail pane with F4
  • Maximize/restore with standard window controls

Always on Top

Enable "Always on Top" from the View tab to keep the window above other applications during debugging sessions.

Transparency

Adjust window transparency (View tab) to see through to underlying applications while monitoring debug output.

Column Customization

Right-click column headers to:

  • Show/hide columns
  • Auto-size columns
  • Reset to default widths
  • Save column layout

Context Menus

Right-click in different areas for context-sensitive options:

  • Message list: Copy, filter, highlight, bookmark
  • Tab bar: New tab, rename, close, duplicate
  • Detail pane: Copy, format, export

Keyboard Focus

Use these keys to navigate:

  • Tab: Move between panes
  • Arrow keys: Navigate messages
  • Page Up/Down: Scroll message list
  • Ctrl+Tab: Switch between tabs
Tip: Use Ctrl+L to quickly jump to the latest message when auto-scroll is disabled.
