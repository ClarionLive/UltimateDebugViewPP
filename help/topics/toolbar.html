Toolbar and Menus

Navigate UltimateDebugView++ using the toolbar and menu system.

Toolbar Overview

The toolbar provides quick access to frequently used functions. Buttons include:

  • Clear: Clear all messages from the current view
  • Save: Save captured messages to file
  • View Log: Open saved log files
  • Global Win32: Toggle global Win32 OutputDebugString capture
  • Capture: Start/stop message capture
  • Auto Scroll: Toggle automatic scrolling to new messages
  • Time: Show/hide timestamp column
  • Font: Change display font
  • Filter: Manage message filters
  • Link Views: Synchronize multiple view tabs
  • Bookmark: Set/navigate bookmarks
  • Process Colors: Color-code messages by process

Expanded Toolbar Feature

For improved readability, enable the Expanded Toolbar option:

  1. Go to Options → Expanded Toolbar
  2. The toolbar switches to a more readable format with text labels
  3. Each button displays both icon and descriptive text
  4. Ideal for high-resolution displays or when learning the interface

Benefits of Expanded Toolbar

  • Clearer button identification
  • Reduced learning curve for new users
  • Better accessibility
  • No need to memorize icon meanings

Menu Bar

The menu bar organizes all features into logical categories:

File Menu

  • New View (Ctrl+N): Create a new message view tab
  • Open... (Ctrl+O): Load saved log files
  • Run...: Execute external programs
  • Save Selection (Alt+S): Save only selected messages
  • Save View (Ctrl+S): Save current filtered view
  • Save Log (Ctrl+Shift+S): Save all captured messages
  • Load Configuration...: Load saved settings and filters
  • Save Configuration...: Save current settings and filters
  • Preferences...: Open the comprehensive Preferences dialog (see Preferences)
  • Exit: Close application

Edit Menu

  • Copy: Copy selected messages
  • Select All: Select all messages
  • Find: Search within messages
  • Filter: Quick filter options

Log Menu

  • Sources: Manage message sources
  • History: View message history
  • Highlight Filters: Configure highlighting
  • Process Include/Exclude: Filter by process
  • Clear View: Clear current view

View Menu

  • Process Colors: Enable process coloring
  • Auto Scroll: Toggle auto-scroll
  • Show Timestamps: Toggle time column
  • Filter: Show filter dialog
  • Find: Search messages
  • Bookmarks: Manage bookmarks

Options Menu

  • Link Views: Synchronize view navigation
  • Auto Newline: Append newlines to messages
  • Prefix PID: Add process ID prefix
  • Font: Configure display font
  • Always On Top: Keep window on top
  • Hide When Minimized: Hide in system tray
  • Expanded Toolbar: Toggle expanded toolbar with text labels
  • Import DebugView++ Settings: Import settings from DebugView++

Help Menu

  • Help Topics: Open this help system
  • About: Version and credits

Toolbar Customization

The toolbar automatically adjusts to window size:

  • Icons only in compact mode (default)
  • Icons with text labels in expanded mode
  • Automatic wrapping on narrow windows
  • Settings persist between sessions

Keyboard Access

Access toolbar functions via keyboard:

  • Alt key: Activate menu bar
  • Accelerators: Use underlined letters in menus
  • Shortcuts: Direct keyboard shortcuts for common functions
Tip: Enable Expanded Toolbar through Options menu for better readability, especially on high-DPI displays.
