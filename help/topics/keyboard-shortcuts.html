Keyboard Shortcuts

Master these keyboard shortcuts to work efficiently with UltimateDebugView++. Most commands are accessible without touching the mouse.

Press Alt in the main window to reveal keyboard accelerators for Ribbon commands.

Essential Shortcuts

These are the most frequently used shortcuts you should memorize:

Shortcut Action Description
Space Pause/Resume Toggle message capture
Ctrl+X Clear View Remove all messages from current view
F5 Filter Dialog Open filter configuration
Ctrl+F Find Search for text in messages
Ctrl+C Copy Copy selected messages

File Operations

Shortcut Action Description
Ctrl+N New View Create a new view tab
Ctrl+O Open File Open a log file or start monitoring
Ctrl+S Save View Save current view to file
Alt+S Save Selection Save only selected messages
Ctrl+W Close Tab Close current view tab
Alt+F4 Exit Close application

View Control

Shortcut Action Description

Scroll Lock Auto Scroll Toggle automatic scrolling
Home Go to Start Jump to first message
End Go to End Jump to last message
Page Up Page Up Scroll up one page
Page Down Page Down Scroll down one page
Ctrl++ Zoom In Increase font size
Ctrl+- Zoom Out Decrease font size
Ctrl+0 Reset Zoom Reset to default font size

Filtering Shortcuts

Shortcut Action Description
Ctrl+I Include Include messages with selected text
Ctrl+E Exclude Exclude messages with selected text
Ctrl+H Highlight Highlight messages with selected text
Ctrl+K Token Filter Create token filter from selection
Ctrl+Shift+F Clear Filters Remove all active filters
Alt+F Filter by Process Filter by selected message's process

Search Navigation

Shortcut Action Description
F3 Find Next Jump to next search match
Shift+F3 Find Previous Jump to previous search match
Ctrl+G Go to Line Jump to specific line number
Esc Cancel Search Close search bar

Bookmarks

Pro Tips

  • Hold Shift while clicking to select multiple messages
  • Hold Ctrl for non-contiguous selection
  • Double-click a message to view details in a popup
  • Middle-click a tab to close it quickly
