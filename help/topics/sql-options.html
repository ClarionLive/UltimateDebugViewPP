Available Options

Keyword Formatting

  • Case: Upper, Lower, Capitalize
  • Line breaks: Before/After keywords
  • Alignment: Left, Right

Indentation Settings

  • Type: Spaces or Tabs
  • Size: 2, 4, 8 characters
  • Nested queries: Additional indent
  • Join clauses: Indent level

Comma Positioning

  • Trailing: item1, item2, item3
  • Leading: item1 ,item2 ,item3
  • Aligned: Column alignment

Parentheses Style

  • Same line: WHERE (condition)
  • New line: WHERE
    (condition)
  • Indent content: Internal indentation

Function Formatting

  • Compact: COUNT(*)
  • Expanded: COUNT( * )
  • Multi-line: Complex functions
