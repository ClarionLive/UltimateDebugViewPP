API Method Reference

Complete reference of all UltimateDebug API methods.

Core Methods

MethodDescription
Debug(STRING pDebugString, <STRING pCustomPrefix>, BYTE pNoClip=0, BYTE pForce=0, <STRING pID>)Output debug message with optional prefix and control flags
Init(<STRING pProcedure>, <STRING pModuleName>, <STRING pAppName>, <STRING pModified>)Initialize procedure tracking, returns LONG procedure ID
EndOfProcedure(LONG pID)Mark procedure exit using ID from Init()
ClearDebugView()Clear output window (sends DBGVIEWCLEAR)
NewFilteredView()Create a new filtered view tab

Data Methods

MethodDescription
DebugQueue(*QUEUE pQueue, <STRING pMsg>, <BYTE pNoTouch>, BYTE pSendToDebugView=0, LONG pMaximumRecords=30)Display queue contents
DebugGroup(*GROUP pGroup, <STRING pMsg>, <STRING pStructureType>, BYTE pSendToDebugView=0)Display group structure
DebugRecord(*FILE pFile, <STRING pMsg>)Display current record from file

Event Methods

MethodDescription
DebugEvent(<STRING pDebugProcedure>)Log Windows event information
IgnoreEvent(SIGNED Event)Add event to ignore list
TakeEvent()Process current event
LogEvent()Log event to queue

Configuration Methods

MethodDescription
SetPrefix(STRING pPrefix)Set default message prefix
BeginTemporaryPrefix(STRING pPrefix)Push temporary prefix onto stack
EndTemporaryPrefix()Pop temporary prefix from stack
SetApplicationName(STRING pApplicationName, STRING pProgramExtension)Set application name
SetShortApplicationName(STRING pApplicationName, STRING pProgramExtension)Set short application name
Enable()Enable debug output
Disable()Disable debug output
AddCategoryToDebug(STRING pCategory)Add debug category
AddProcedureException(STRING pProcedureName)Exclude procedure from output
RemoveProcedureException(STRING pProcedureName)Remove procedure exclusion
EmptyProcedureExceptions()Clear all procedure exclusions

Tracing Methods

MethodDescription
TurnOnTracing(FILE pFile)Enable SQL tracing for file
TurnoffTracing(FILE pFile)Disable SQL tracing for file (note: lowercase 'off')
GetFieldNames(FILE pFile)Get field names from file structure

Error Handling Methods

MethodDescription
Error(<STRING pMessage>)Log error with ERRORCODE() info, returns BYTE
ErrorCode(<STRING pMessage>)Log error code information, returns BYTE
InitAssertHook()Initialize assertion hook handler

Utility Methods

MethodDescription
DecToHex(LONG pNumber)Convert decimal to hexadecimal string
Message(STRING pDebugString)Display message dialog
ShowProcedureInfo(STRING pProcedure, STRING pApplication, STRING pHelpID, STRING pCreated, STRING pModified, STRING pCompiled)Display procedure information
FormatMessageList(STRING pMsg, *QUEUE pMsgQueue)Format message into queue
