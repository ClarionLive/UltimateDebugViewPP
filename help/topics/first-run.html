First Run

Get started with UltimateDebugView++ and configure it for your debugging needs.

Initial Setup

When you first launch UltimateDebugView++, the application automatically begins capturing Win32 OutputDebugString messages from all processes on your system.

Default Configuration

  • Auto-capture: Enabled for Win32 debug messages
  • Buffer size: 100,000 messages (configurable)
  • Timestamp format: HH:MM:SS.mmm
  • Line wrapping: Disabled
  • Auto-scroll: Enabled

Essential First Steps

1. Configure Message Sources

Use the toolbar buttons or Log menu to:

  • Enable/disable Win32 capture
  • Add file monitoring sources
  • Configure network listeners (TCP/UDP)
  • Set up DebugView Agent connections

2. Set Up Filters

Use the Filter button on the toolbar to:

  • Create include filters to show only relevant messages
  • Add exclude filters to hide noise
  • Configure highlighting for important patterns
  • Save filter sets for different debugging scenarios

3. Customize the View

Adjust the display to your preferences:

  • Toggle column visibility (Time, Process, Message)
  • Adjust column widths
  • Configure font and colors
  • Enable syntax highlighting for code snippets

Performance Considerations

For optimal performance on first run:

  • Limit buffer size if capturing high-volume output
  • Use filters to reduce displayed messages
  • Disable auto-scroll when reviewing past messages
  • Consider process-specific capture for targeted debugging

Saving Your Configuration

Your settings are automatically saved and restored between sessions. Configuration is stored in:

%APPDATA%\UltimateDebugViewPP\settings.xml
