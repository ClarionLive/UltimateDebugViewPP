Quick Start Guide

Get started with UltimateDebugView++ in just a few minutes. This guide covers the essentials to begin capturing and analyzing debug messages.

Installation

Download the Application

Download UltimateDebugviewpp.exe from the official repository.

Extract Files

Extract the archive to your preferred location (e.g., C:\Program Files\UltimateDebugView++).

Run the Executable

Double-click UltimateDebugviewpp.exe to launch. No installation required!

For capturing kernel messages, right-click the executable and select "Run as Administrator".

First Launch

When you first run UltimateDebugView++:

  • The application automatically starts capturing Win32 OutputDebugString messages
  • The main window displays with the toolbar and menu system at the top
  • A default configuration is created in %APPDATA%\UltimateDebugView++
  • The message list area is ready to display incoming debug output

Basic Operations

Viewing Debug Messages

Messages appear automatically as your applications output debug information. Each message shows:

  • Index: Sequential message number
  • Time: Timestamp of the message
  • Process: Name and ID of the source application
  • Message: The actual debug output

Your First Debug Session

Test with a Simple Message

To verify UltimateDebugView++ is working, you can send a test message:

From Command Line (PowerShell):

Add-Type -TypeDefinition @"
    using System;
    using System.Runtime.InteropServices;
    public class Debug {
        [DllImport("kernel32.dll")]
        public static extern void OutputDebugString(string message);
    }
"@
[Debug]::OutputDebugString("Hello from UltimateDebugView++!")

From C++ Application:

#include 

int main() {
    OutputDebugString(L"Hello from C++!");
    return 0;
}

From Clarion Application:

INCLUDE('UltimateDebug.INC'),ONCE

MyDebug  UltimateDebug

CODE
    MyDebug.Debug('Hello from Clarion!')

Quick Filtering

Focus on specific messages quickly:

Include Filter

Select text in a message, press Ctrl+I to show only messages containing that text.

Exclude Filter

Select text, press Ctrl+E to hide messages with that text.

Highlight

Select text, press Ctrl+H to color-code matching messages.

Common Use Cases

Debugging a Specific Process

  1. Start UltimateDebugView++
  2. Launch your application
  3. Right-click on a message from your app
  4. Select "Filter by Process" to see only its messages

Finding Errors Quickly

  1. Press F5 to open filters
  2. Add a highlight filter for "error" (case-insensitive)
  3. Choose red color for easy visibility
  4. All error messages will now be highlighted in red

Saving Important Sessions

  1. Capture your debug session
  2. Click File â†’ Save (or press Ctrl+S)
  3. Choose a location and filename
  4. Later, use File â†’ Open to review the saved session

Tips for Effective Debugging

  • Use prefixes: Start messages with [INFO], [ERROR], [SQL] for easy filtering
  • Create views: Press Ctrl+N for separate filtered views
  • Bookmark important messages: Press Ctrl+F2 to bookmark
  • Export for analysis: Save filtered results as CSV for spreadsheet analysis
  • Use regex: Enable regex in filters for powerful pattern matching
Remember to clear old messages periodically (Ctrl+X) to maintain performance when debugging high-volume applications.
