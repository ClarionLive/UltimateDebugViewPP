Automatic SQL Detection

How UltimateDebugView++ identifies and processes SQL statements in debug messages.

Detection Methods

1. Keyword Detection

Recognizes SQL keywords at message start:

  • SELECT, INSERT, UPDATE, DELETE
  • CREATE, ALTER, DROP
  • EXEC, EXECUTE, CALL
  • WITH (CTE queries)

2. Prefix Detection

Messages with SQL indicators:

  • [SQL] prefix
  • [QUERY] prefix
  • SQL: at start
  • Query: at start

3. Pattern Recognition

Common SQL patterns:

  • FROM table_name
  • WHERE conditions
  • JOIN clauses
  • Parameter markers (?, @param, :param)

Improving Detection

Best Practices

  • Use [SQL] prefix for guaranteed detection
  • Start messages with SQL keywords
  • Include complete SQL statements
  • Avoid mixing SQL with other text

Example Messages

// Good - Will be detected
"[SQL] SELECT * FROM users"
"SELECT id, name FROM customers WHERE active = 1"
"SQL: INSERT INTO logs (message) VALUES (?)"

// Poor - May not be detected
"Running query: select data"
"The SELECT statement failed"
"Error in: SELECT * FROM..."

Detection Settings

Configure detection sensitivity:

  • Strict: Only explicit SQL markers
  • Normal: Keywords and patterns
  • Aggressive: Any SQL-like content
