Message Highlighting

Use colors and styles to make important messages stand out.

Highlight Features

  • 16 predefined colors
  • Custom RGB color selection
  • Background and foreground colors
  • Bold and italic text styles
  • Multiple highlight rules

Creating Highlight Rules

  1. Go to Filter tab
  2. Click Add Highlight
  3. Enter pattern to match
  4. Choose colors and style
  5. Set priority (higher = more important)
  6. Click OK

Highlight Priority

When multiple rules match:

  • Higher priority rules win
  • Last matching rule applies
  • Drag to reorder rules
  • Number indicates priority

Tips for Effective Highlighting

  • Use contrasting colors for clarity
  • Limit number of colors to avoid confusion
  • Reserve red for critical issues
  • Use subtle colors for common messages
  • Test visibility in both light/dark themes
