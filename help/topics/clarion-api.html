UltimateDebug Class API

Complete API reference for the Clarion UltimateDebug class.

Core Methods

Debug(string Message)

Output a debug message:

ud.Debug(''Customer ID: '' & CUS:ID)

Init(string ProcedureName)

Initialize procedure tracking:

ud.Init(''UpdateCustomer'')
! Procedure code
ud.EndOfProcedure()

EndOfProcedure()

Mark procedure exit (pairs with Init).

Data Structure Methods

DebugQueue(*QUEUE Q)

Display queue contents:

ud.DebugQueue(CustomerQueue)

DebugGroup(*GROUP G)

Display group structure:

ud.DebugGroup(CustomerRecord)

DebugRecord()

Display current file record:

GET(Customer, CUS:ID)
ud.DebugRecord()

Event Methods

DebugEvent()

Log Windows event:

CASE EVENT()
OF EVENT:Accepted
    ud.DebugEvent()
END

SetEventsToDebug(string Events)

Filter events to log:

ud.SetEventsToDebug(''EVENT:Accepted|EVENT:Selected'')

Configuration Methods

SetPrefix(string Prefix)

Set message prefix:

ud.SetPrefix(''[MODULE]'')

SetApplicationName(string Name)

Set application identifier:

ud.SetApplicationName(''CustomerManager'')

SetModuleName(string Name)

Set module identifier:

ud.SetModuleName(''Billing'')

SQL Methods

SQL(string Query)

Log formatted SQL:

ud.SQL(''SELECT * FROM Customers WHERE Active = 1'')

EnableSQLTrace()

Enable automatic SQL logging.

Utility Methods

ClearDebugView()

Clear debug output window:

ud.ClearDebugView()

Error(string Message)

Log error with [ERROR] prefix:

ud.Error(''Failed to save: '' & ERROR())

Assert(BYTE Condition, string Message)

Conditional assertion:

ud.Assert(CUS:ID > 0, ''Invalid customer ID'')

Properties

Enabled

Enable/disable all output:

ud.Enabled = TRUE  ! Enable debugging
ud.Enabled = FALSE ! Disable for production

ShowThreadID

Include thread ID in messages:

ud.ShowThreadID = TRUE

ShowTimestamp

Include timestamps:

ud.ShowTimestamp = TRUE

Advanced Features

Conditional Debugging

ud.AddCategoryToDebug(''CustomerUpdate'')
ud.DebugIf(''CustomerUpdate'', ''Updating ID: '' & CUS:ID)

Performance Timing

ud.StartTimer(''QueryExecution'')
! Execute query
ud.StopTimer(''QueryExecution'')
