Clarion Code Examples

Practical examples of using UltimateDebug in Clarion applications.

Basic Setup

! Global data section
INCLUDE(''UltimateDebug.inc''),ONCE
ud  UltimateDebug

! Program initialization
ud.Init()
ud.SetApplicationName(''CustomerManager'')
ud.Enabled = TRUE

Procedure Tracking

UpdateCustomer PROCEDURE
CODE
    ud.Init(''UpdateCustomer'')
    ud.Debug(''Customer ID: '' & CUS:ID)

    ! Update logic here

    ud.EndOfProcedure()
    RETURN

Error Handling

IF ERRORCODE()
    ud.Error(''Database error: '' & ERROR())
    ud.Debug(''Failed on Customer: '' & CUS:ID)
    MESSAGE(ERROR())
END

Queue Debugging

! Display queue contents
LOOP I# = 1 TO RECORDS(MyQueue)
    GET(MyQueue, I#)
    ud.Debug(''Queue['' & I# & '']: '' & MyQueue.Field)
END

! Or use built-in method
ud.DebugQueue(MyQueue)

SQL Logging

! Log SQL queries
SQLString = ''SELECT * FROM Customers WHERE Active = 1''
ud.SQL(SQLString)
PROP:SQL = SQLString

! Enable automatic SQL trace
ud.EnableSQLTrace()

Event Debugging

! In window procedure
OF EVENT:Accepted
    ud.DebugEvent()
    CASE FIELD()
    OF ?OK
        ud.Debug(''OK button clicked'')
    OF ?Cancel
        ud.Debug(''Cancel button clicked'')
    END

Conditional Debugging

! Debug only specific operations
IF DEBUG:DetailedLogging
    ud.AddCategoryToDebug(''DatabaseOperations'')
END

! Later in code
ud.DebugIf(''DatabaseOperations'', ''Executing query: '' & SQLString)

Performance Profiling

! Time critical operations
ud.StartTimer(''DatabaseQuery'')
! ... database operation ...
ud.StopTimer(''DatabaseQuery'')

! Manual timing
StartTime = CLOCK()
! ... operation ...
ud.Debug(''Operation took: '' & (CLOCK() - StartTime) & '' ms'')
