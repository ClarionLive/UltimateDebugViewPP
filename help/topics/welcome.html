Key Features

Message Capture

Capture debug output from multiple sources simultaneously:

  • Win32 OutputDebugString API
  • Real-time log file monitoring (tailing)
  • Network messages via TCP/UDP
  • Remote debugging with DebugView Agent
  • Named pipes and command-line input

Advanced Filtering

Find exactly what you need with powerful filtering options:

  • Include/Exclude filters with regex support
  • Color-coded highlighting for instant recognition
  • Process-based filtering
  • Token extraction using capture groups
  • Save and load filter sets

Developer Tools

Professional features for serious debugging:

  • Syntax highlighting for code snippets
  • Bookmarks for marking important messages
  • Multiple export formats (CSV, JSON, XML, HTML)
  • Tabbed views with independent filters
  • Command-line automation support
