SQL Formatting

Automatic SQL query beautification powered by the fsqlf formatter.

Features

  • Automatic SQL detection in messages
  • Real-time query formatting
  • Syntax highlighting
  • Multiple formatting styles
  • Customizable formatting options

Automatic Detection

SQL queries are detected when messages contain:

  • SQL keywords (SELECT, INSERT, UPDATE, DELETE)
  • [SQL] prefix in message
  • Common SQL patterns
  • Database error messages with queries

Formatting Options

Keyword Case

  • Upper: SELECT, FROM, WHERE
  • Lower: select, from, where
  • Capitalize: Select, From, Where

Indentation

  • Type: Spaces or Tabs
  • Size: 2, 4, or 8 spaces
  • Nested: Indent subqueries

Line Breaks

  • Before/after keywords
  • Comma positioning
  • Parentheses style
  • Join clause formatting

Formatting Examples

Compact Style

SELECT id, name FROM users WHERE active = 1

Expanded Style

SELECT
    id,
    name
FROM
    users
WHERE
    active = 1

Standard Style

SELECT id, name
FROM users
WHERE active = 1

Using SQL Formatting

Automatic Formatting

  1. SQL queries are auto-detected
  2. Formatted in detail pane
  3. Syntax highlighting applied

Manual Formatting

  1. Select message with SQL
  2. Press F4 for detail pane
  3. Click Format SQL button
  4. Copy formatted result

Configuration

Configure SQL formatting in Settings:

  1. Go to Tools â†’ Settings
  2. Select SQL Formatting tab
  3. Adjust formatting options
  4. Preview with sample SQL
  5. Click Apply

Supported SQL Features

  • Standard SQL (SELECT, INSERT, UPDATE, DELETE)
  • DDL statements (CREATE, ALTER, DROP)
  • Joins (INNER, LEFT, RIGHT, FULL)
  • Subqueries and CTEs
  • Functions and expressions
  • Comments (-- and /* */)
Tip: Use the [SQL] prefix in your debug messages to ensure automatic SQL detection and formatting.
