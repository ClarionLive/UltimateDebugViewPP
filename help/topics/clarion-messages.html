Clarion Message Format

Understanding the structured format of Clarion debug messages.

Message Structure

[||]X,T:123,P:UpdateCustomer,M:Customer,A:MyApp,PRE:[Info],MSG:Processing record

Components Explained

  • [||]: Clarion message identifier
  • X: Message type (O=Open, C=Close, M=Message)
  • T:123: Thread ID
  • P:UpdateCustomer: Current procedure
  • M:Customer: Module name
  • A:MyApp: Application name
  • PRE:[Info]: Message prefix/category
  • MSG:Processing record: Actual message

Message Types

  • O (Open): Procedure entry
  • C (Close): Procedure exit
  • M (Message): Regular debug message
  • E (Event): Windows event
  • Q (Queue): Queue data
  • G (Group): Group data
  • S (SQL): SQL query

Parsing in UltimateDebugView++

Messages are automatically parsed to extract:

  • Thread information for filtering
  • Procedure names for call stack
  • Module/Application for categorization
  • Prefixes for highlighting
  • Content for formatting

Custom Message Formatting

Create custom formatted messages:

ud.SetFormat(''[||]X,T:{{thread}},APP:{{app}},MSG:{{message}}'')
