Detail Pane

View and analyze message details with syntax highlighting and formatting.

Overview

The detail pane provides an enhanced view of selected messages with:

  • Syntax highlighting for various languages
  • Automatic SQL formatting
  • JSON/XML structure visualization
  • Line numbers and text wrapping
  • Search and navigation within content

Accessing the Detail Pane

  • Toggle: Press F4 or View → Detail Pane
  • Auto-show: Double-click any message
  • Resize: Drag the splitter between panes
  • Position: Bottom (default) or right side

Features

Syntax Highlighting

Automatically detects and highlights:

  • SQL: Keywords, functions, strings, comments
  • JSON: Keys, values, arrays, objects
  • XML/HTML: Tags, attributes, content
  • C++/C#: Keywords, types, strings, comments
  • JavaScript: Keywords, functions, objects
  • Python: Keywords, functions, strings
  • Clarion: Keywords, procedures, variables

SQL Formatting

When SQL is detected:

  1. Automatic beautification applied
  2. Proper indentation and line breaks
  3. Keyword capitalization
  4. Click Format SQL for manual formatting

Text Operations

  • Copy: Ctrl+C or right-click menu
  • Select All: Ctrl+A
  • Find: Ctrl+F for search within content
  • Word Wrap: Toggle with toolbar button
  • Zoom: Ctrl+Mouse Wheel

Toolbar Controls

The detail pane toolbar provides:

  • Copy: Copy selected or all text
  • Format: Apply formatting (SQL, JSON, XML)
  • Wrap: Toggle word wrapping
  • Numbers: Show/hide line numbers
  • Language: Override syntax highlighting
  • Export: Save content to file

Navigation

Within the Pane

  • Scroll: Mouse wheel or scrollbars
  • Jump to line: Ctrl+G
  • Find next: F3
  • Find previous: Shift+F3

Between Messages

  • Next message: Down arrow in main list
  • Previous message: Up arrow in main list
  • Keep focus: Lock pane with pin button

Advanced Features

Code Folding

For structured content (JSON, XML, code):

  • Click fold markers in margin
  • Ctrl+Shift+[ to fold current block
  • Ctrl+Shift+] to unfold
  • Alt+0 to fold all
  • Alt+Shift+0 to unfold all

Bookmarks

  • Set: Ctrl+F2 on a line
  • Next: F2
  • Previous: Shift+F2
  • Clear all: Ctrl+Shift+F2

Multi-Selection

  • Ctrl+Click for multiple cursors
  • Alt+Drag for column selection
  • Ctrl+D to select next occurrence

Context Menu

Right-click in the detail pane for:

  • Copy/Cut/Paste operations
  • Format selection
  • Change syntax highlighting
  • Export to file
  • Print preview

Customization

Appearance

  • Font: Settings → Detail Pane → Font
  • Colors: Settings → Syntax Colors
  • Theme: Light/Dark theme support

Behavior

  • Auto-format SQL: Enable/disable
  • Auto-detect language: Configure detection
  • Tab size: Spaces vs tabs
  • Line endings: Windows/Unix/Mac

Performance Tips

  • Disable syntax highlighting for very large messages
  • Turn off auto-format for high-volume capture
  • Use the pin feature to prevent constant updates
  • Close detail pane when not needed
Tip: Use Shift+F4 to quickly copy the current message to clipboard without opening the detail pane.
