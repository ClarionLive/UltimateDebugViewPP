MCP Tool Reference

The 30 tools an AI assistant can use through the built-in MCP server. See AI Assistants (MCP) for setup.

You never call these tools yourself: you ask your assistant in plain words and it picks them. This page explains what each one does, so you know what to ask for.

Line numbers and cursors

Every captured line has a line number that only goes up, even after the log is cleared. Read tools return nextLine. When the assistant passes it back as since_line, it gets only what is new. insert_marker returns the same kind of number, so "everything after the marker" is exact.

Status and reading

ToolWhat it doesMain parameters
get_statusVersion, tool list, capture state, current cursor, tabs, masking and save-folder settings.none
read_messagesReads lines, oldest first, from the whole log or one tab. Identical consecutive lines are folded into one with a repeat count.tab, since_line, limit, tail, contains, regex, process, pid
search_messagesFinds lines and returns each with the lines around it.pattern, regex, context, limit, tab
wait_for_messagesWaits (up to 55 seconds per call) until matching lines arrive. The viewer stays responsive.since_line, contains, regex, count, timeout_seconds
list_processesPrograms that wrote to the log, with line counts and first/last seen times.none
get_message_detailEverything about one line: Clarion fields (thread, procedure, module, call depth, open/close), queue, error fields, detected format, and formatted text (SQL with your formatting options).line

Tabs and filters

ToolWhat it doesMain parameters
list_tabsAll tabs, with lines shown, filter count and who created them.none
create_tabA new tab named AI: <name>, optionally with filters.name, filters, select
switch_tabShows a tab.tab
rename_tab, close_tabFor the assistant's own tabs, or yours when you asked (allow_user_tab). The first tab never closes.tab, name
get_filtersA tab's filters.tab
set_filters, add_filter, remove_filter, enable_filterReplace, add, remove, or switch filters on and off.tab, filter fields

A filter has a text, a matchType (simple, wildcard, regex, regexgroups, regexcase), a filterType (include, exclude, highlight, token, stop, track, once, clear, beep, matchcolor, bookmark), a category (message, process, prefix, procedure), colours (#RRGGBB) and enabled.

Clarion

ToolWhat it doesMain parameters
get_procedure_statsOpen/close counts per procedure, most unbalanced first, and what is open now on each thread. unbalanced above 0 means opened more often than closed.procedure, unbalanced_only, tab
get_procedure_timelineOpens and closes in order, with call depth and durations.since_line, procedure, thread
list_queues, get_queueQueues dumped with UltimateDebug, then their headers and rows.queue_id, offset, limit
create_procedure_viewA tab (AI: Proc: <name>) showing one procedure's lines.procedure

Saving

ToolWhat it doesMain parameters
save_logSaves the log, or one program's lines, to a new file in the folder you chose in Preferences.path (file name only), process
save_viewSaves the lines a tab shows.path, tab, process

With A folder per program on and several programs in the log, a save returns the list of programs, and the assistant asks you which one before saving.
