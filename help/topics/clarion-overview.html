Clarion Integration Overview

Enhanced debugging support specifically designed for Clarion developers.

Clarion-Specific Features

  • UltimateDebug Class: Comprehensive debugging API
  • Procedure Tracking: Call stack visualization
  • Queue/Group Display: Formatted data structures
  • Event Monitoring: Windows event tracking
  • SQL Tracing: Database query logging
  • Thread Management: Multi-thread debugging

Message Format

Clarion messages use a structured format:

[||]X,T:<thread>,P:<procedure>,M:<module>,A:<app>,PRE:<prefix>,MSG:<message>

Format Components

  • [||]: Clarion message marker
  • X: Message type indicator
  • T: Thread ID
  • P: Current procedure
  • M: Module name
  • A: Application name
  • PRE: Message prefix/category
  • MSG: Actual message content

Special Prefixes

UltimateDebugView++ recognizes Clarion prefixes:

  • [Open]: Procedure entry
  • [Close]: Procedure exit
  • [Queue]: Queue data display
  • [Group]: Group data display
  • [Events]: Windows events
  • [Assert]: Assertion messages
  • [ERROR]: Error conditions
  • [SQL]: SQL queries
  • [Trace]: Execution trace

Procedure Tracking

Advanced call stack visualization:

  • Automatic procedure entry/exit detection
  • Call hierarchy display
  • Execution timing statistics
  • Thread-aware tracking
  • Performance profiling

Getting Started

  1. Include UltimateDebug class in your application
  2. Initialize in program setup: 
    ud.Init()
ud.SetApplicationName(AppName)
  3. Add procedure tracking: 
    ud.Init(ProcedureName)
! Your code here
ud.EndOfProcedure()
  4. Use debug methods throughout code
