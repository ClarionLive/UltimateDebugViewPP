Saved Filters

Save and manage filter configurations for different debugging scenarios.

Saving Filter Sets

  1. Configure your filters
  2. Click Edit menu - Save Filter Set
  3. Enter a descriptive name
  4. Optional: Add description
  5. Click Save

Loading Filter Sets

  1. Click Edit menu - Load Filter Set
  2. Select from saved sets
  3. Choose load option:
    • Replace: Clear existing filters
    • Append: Add to existing filters
  4. Click Load

Managing Filter Sets

  • Edit: Modify saved filter sets
  • Delete: Remove unused sets
  • Export: Share with team members
  • Import: Load shared filter sets
  • Set as Default: Auto-load on startup

Common Filter Set Examples

Production Monitoring

  • Include: ERROR|CRITICAL|FATAL
  • Exclude: DEBUG|TRACE
  • Highlight: CRITICAL (Red)
  • Beep: FATAL

Development Debugging

  • Include: MyComponent
  • Highlight: SQL (Blue)
  • Highlight: ERROR (Red)
  • Bookmark: Exception

Performance Analysis

  • Include: PERF|TIMING|SLOW
  • Exclude: INFO|DEBUG
  • Highlight: >1000ms (Orange)
  • Track: Memory usage

Filter Set Storage

Filter sets are stored in:

  • Windows Registry (per-user)
  • Export to XML files
  • Shareable configuration files
