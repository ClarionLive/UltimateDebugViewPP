Include/Exclude Filters

Fine-tune message visibility with include and exclude filters.

Include Filters

Show only messages that match specified patterns:

  • Focus on specific components
  • Monitor particular error types
  • Track specific processes
  • Filter by message content

Include Filter Examples

// Show only SQL queries
Pattern: "SELECT|INSERT|UPDATE|DELETE"
Type: Regex

// Show specific process
Pattern: "MyApp.exe"
Type: Simple

// Show error levels
Pattern: "ERROR|CRITICAL|FATAL"
Type: Regex

Exclude Filters

Hide messages matching patterns:

  • Remove noise and clutter
  • Hide verbose logging
  • Filter out known issues
  • Suppress repetitive messages

Exclude Filter Examples

// Hide trace logging
Pattern: "[TRACE]"
Type: Simple

// Hide heartbeat messages
Pattern: "keepalive|ping|heartbeat"
Type: Regex

// Hide specific DLLs
Pattern: "*.dll"
Type: Wildcard

Combining Filters

Use both include and exclude for precise control:

  1. Exclude filters run first (remove unwanted)
  2. Include filters run second (keep wanted)
  3. Result: Only desired messages shown

Example Combination

Exclude: "TRACE|DEBUG"  // Remove verbose
Include: "MyComponent"   // Show only my component
Result: MyComponent messages without TRACE/DEBUG

Filter Management

  • Enable/Disable: Toggle filters without deleting
  • Reorder: Drag filters to change priority
  • Edit: Double-click to modify
  • Groups: Organize filters into sets
