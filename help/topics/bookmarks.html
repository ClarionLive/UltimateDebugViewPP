Bookmarks

Mark important messages for quick navigation.

Creating Bookmarks

  • Manual: Ctrl+F2 on selected message
  • Right-click: Toggle Bookmark
  • Auto-bookmark: Filter-based bookmarking

Navigation

  • Next bookmark: F2
  • Previous bookmark: Shift+F2
  • Bookmark list: Ctrl+Shift+B
  • Clear all: Ctrl+Shift+F2

Auto-Bookmarking

Create filters that automatically bookmark:

  1. Add filter with "Bookmark" action
  2. Define pattern (e.g., "ERROR")
  3. Messages automatically bookmarked

Bookmark Management

  • Export bookmarks to file
  • Add notes to bookmarks
  • Group related bookmarks
  • Search within bookmarks
