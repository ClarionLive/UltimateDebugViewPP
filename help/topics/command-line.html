Command Line Options

Launch UltimateDebugView++ with specific configurations.

Basic Usage

UltimateDebugviewpp.exe [options] [filename]

Available Options

  • /min: Start minimized
  • /max: Start maximized
  • /config:file: Load configuration
  • /filter:file: Load filter set
  • /log:file: Start logging to file
  • /udp:port: Start UDP listener
  • /tcp:host:port: Connect to TCP agent

File Loading

Load saved debug logs:

UltimateDebugviewpp.exe "C:\Logs\debug.log"

Multiple Files

Open multiple files:

UltimateDebugviewpp.exe file1.log file2.log file3.log

Automation Examples

# Start with UDP listener
UltimateDebugviewpp.exe /udp:9999

# Load configuration and filter
UltimateDebugviewpp.exe /config:production.xml /filter:errors.filter

# Start minimized with logging
UltimateDebugviewpp.exe /min /log:output.txt
