Troubleshooting

Solutions to common issues and problems.

No Messages Appearing

  • Verify capture is enabled (check status bar)
  • Ensure no other debugger is attached
  • Check filters aren''t hiding all messages
  • Run as administrator for global capture
  • Verify application is using OutputDebugString

Missing Messages

  • Check exclude filters
  • Verify buffer isn''t full
  • Look for process filters
  • Check time range filters
  • Ensure high message rate isn''t causing drops

High CPU Usage

  • Reduce message volume with filters
  • Increase update interval
  • Disable syntax highlighting
  • Close unused tabs
  • Reduce buffer size

Connection Issues

  • Check firewall settings
  • Verify network connectivity
  • Ensure correct port numbers
  • Check agent is running
  • Test with telnet/nc first

File Access Errors

  • Check file permissions
  • Ensure file isn''t locked
  • Verify path is correct
  • Try running as administrator
  • Check antivirus isn''t blocking
