Views & Tabs

Create and manage multiple views to organize and filter debug output effectively.

Understanding Views

Views are filtered representations of your debug message stream. Each tab represents a different view, allowing you to:

  • Focus on specific processes or components
  • Apply different filter sets to the same data
  • Compare messages from different sources
  • Organize debugging workflows

Creating New Views

Method 1: New Tab Button

  1. Click the New Tab button (+) on the tab bar
  2. Configure filters for the new view
  3. Optionally rename the tab for clarity

Method 2: Duplicate Existing View

  1. Right-click an existing tab
  2. Select Duplicate View
  3. Modify filters as needed

Method 3: Quick Filter

  1. Select text in a message
  2. Right-click and choose Filter in New Tab
  3. A new tab is created with that filter applied

Tab Management

Renaming Tabs

  • Double-click the tab name to edit
  • Right-click → Rename Tab
  • Use descriptive names like "SQL Queries" or "Error Messages"

Reordering Tabs

  • Drag and drop tabs to reorder
  • Ctrl+Shift+Left/Right to move current tab

Closing Tabs

  • Click the X button on the tab
  • Middle-click the tab
  • Ctrl+W to close current tab
  • Right-click → Close Other Tabs

View Types

1. All Messages View

The default view showing all captured messages without filtering. Useful for:

  • Initial exploration
  • Discovering patterns
  • Full context debugging

2. Filtered Views

Views with specific filters applied:

  • Process-specific: Shows messages from one application
  • Error-only: Filters for error patterns
  • Component-based: Focus on specific modules
  • Time-range: Messages within a time window

3. Highlight Views

Views that emphasize certain messages:

  • Color-coded by severity
  • Pattern-based highlighting
  • Multi-level priority marking

View Settings

Each view maintains independent settings for:

  • Include/exclude filters
  • Highlight rules
  • Column visibility and widths
  • Sort order
  • Auto-scroll state

Saving View Configurations

Save Current Layout

  1. Arrange tabs and configure filters
  2. File → Save View Layout
  3. Name your configuration

Load Saved Layout

  1. File → Load View Layout
  2. Select saved configuration
  3. All tabs and filters are restored

Advanced Features

Linked Views

Link tabs to synchronize scrolling and selection:

  1. Right-click tab → Link to...
  2. Select target tab
  3. Navigation in one affects the other

View Templates

Create reusable view templates:

  1. Configure a view with filters
  2. Right-click → Save as Template
  3. Apply template to new tabs

Auto-create Rules

Automatically create new tabs based on:

  • New process detection
  • Specific message patterns
  • Error threshold exceeded

Best Practices

  • Limit active tabs to improve performance
  • Use descriptive tab names
  • Save frequently used layouts
  • Close unnecessary views to reduce memory usage
  • Group related tabs together
Tip: Use Ctrl+1 through Ctrl+9 to quickly switch to the first nine tabs.
