Syntax Highlighting

Automatic syntax highlighting powered by Scintilla and Lexilla.

Supported Languages

  • SQL: Keywords, functions, strings
  • JSON: Keys, values, structures
  • XML/HTML: Tags, attributes, content
  • C/C++: Keywords, types, preprocessor
  • C#: .NET keywords, LINQ
  • JavaScript: ES6+ syntax
  • Python: Keywords, decorators
  • Clarion: Specialized Clarion syntax
  • Log Files: Levels, timestamps

Automatic Detection

Content type is detected by:

  • Message prefixes ([SQL], [JSON], etc.)
  • Content patterns (SELECT, {, <, etc.)
  • File extensions in paths
  • Explicit type markers

Color Themes

  • Light Theme: Optimized for bright displays
  • Dark Theme: Reduced eye strain
  • Custom: Define your own colors
