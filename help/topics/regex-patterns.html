Regular Expression Patterns

Use powerful regex patterns for advanced message filtering and extraction.

Regex Support

UltimateDebugView++ uses standard regex with these match types:

  • Regex: Standard regular expression
  • RegexCase: Case-sensitive regex
  • RegexGroups: Capture groups for extraction

Common Patterns

Error Detection

// Any error keyword
\b(ERROR|EXCEPTION|FAIL|FATAL)\b

// Error with code
ERROR\s+(\d+):\s+(.*)

// Stack trace lines
^\s+at\s+[\w\.]+\(.*\)

Log Level Extraction

// Standard log levels
^\[(TRACE|DEBUG|INFO|WARN|ERROR|FATAL)\]

// Timestamp and level
^(\d{4}-\d{2}-\d{2}\s+\d{2}:\d{2}:\d{2})\s+\[(\w+)\]

SQL Query Detection

// SQL statements
\b(SELECT|INSERT|UPDATE|DELETE|CREATE|DROP)\b.*\bFROM\b

// Parameterized queries
@\w+|:\w+|\?\d*

Performance Metrics

// Execution time
took\s+(\d+(?:\.\d+)?)\s*(ms|seconds?)

// Memory usage
(\d+(?:\.\d+)?)\s*(KB|MB|GB)\s+used

Capture Groups

Extract parts of messages using groups:

// Extract timestamp, level, and message
^(\d{2}:\d{2}:\d{2})\s+\[(\w+)\]\s+(.*)$
Group 1: Timestamp
Group 2: Level
Group 3: Message

Advanced Patterns

IP Address Matching

// IPv4 address
\b(?:\d{1,3}\.){3}\d{1,3}\b

// IPv4 with port
\b(?:\d{1,3}\.){3}\d{1,3}:\d{1,5}\b

File Path Detection

// Windows paths
[A-Z]:\\[\w\\]+\.\w+

// Unix paths
\/[\w\/]+\.\w+

JSON Detection

// JSON object
\{[^{}]*\}

// JSON array
\[[^\[\]]*\]

Regex Tips

  • Use \b for word boundaries
  • Make patterns specific to avoid false matches
  • Test patterns with sample data first
  • Use non-greedy matches (.*?) when appropriate
  • Consider performance with complex patterns

Testing Regex

  1. Open Filter dialog
  2. Select "Regex" match type
  3. Enter pattern
  4. Click "Test" to preview matches
  5. Adjust pattern as needed
Performance: Complex regex patterns can impact performance with high message volumes. Use simpler patterns when possible.
